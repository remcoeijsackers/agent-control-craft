How it works

  1. Every Claude run in this workspace gets the MCP server of each installed Craft app (craft-film, craft-photo, …), plus craft_status and craft_delivery_spec.
  2. The first call to an app's tools asks you in the inbox, unless you allow it under Rights (tool craft-film and so on). In God mode the autonomy rules decide.
  3. Agents save projects and exports in the task's output folder; they appear under Results when the run ends.
  4. Live mode: start the app with --control <port> (any free port); the plugin finds the port on the open app. While it is open, agents work in your window and you can watch; otherwise they work headless.
